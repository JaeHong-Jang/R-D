# 판정 기준 (초안)

상태: **초안, 팀 확정 전** (harness Q-001). 회사 미팅에서 요구한 "거짓 뉴스 판단 기준"이다.
확정되면 이 줄을 지우고 `harness.yaml`의 Q-001을 닫는다.

## 1. 무엇을 판정하는가

기사 전체가 아니라 **문장 속 주장 하나**를 판정한다. 기사 신뢰도는 주장 판정을 모아 나중에 계산한다.

판정 대상은 수집한 기관 자료로 맞는지 틀린지 확인할 수 있는 주장만이다.

| 주장 유형 | 예 | 확인할 근거 자료 |
|---|---|---|
| 의결 | "○○법 개정안이 본회의를 통과했다" | `assembly_bills` 처리결과·처리일 |
| 표결 | "찬성 178표, 반대 0표로 가결됐다" | `assembly_votes` 찬성·반대·기권 수 |
| 발의 | "○○ 의원이 ○○법 개정안을 대표발의했다" | `assembly_bills` 제안자·제안일 |
| 법령 내용 | "현행 ○○법 제9조는 ~를 규정한다" | `law_current` 조문 |
| 헌재 결정 | "헌재가 ○○ 조항에 위헌 결정을 내렸다" | `law_detc` 주문·종국일자 |
| 정부 발표 | "○○부가 ~를 시행한다고 밝혔다" | `policy_news` 본문 |

## 2. 라벨

| 라벨 | 뜻 | 판단 방법 |
|---|---|---|
| `사실` | 근거 자료와 핵심 내용이 모두 맞다 | 대상(법안·의원·조항), 결과(통과·부결 등), 수치, 날짜가 모두 일치 |
| `일부사실` | 핵심은 맞지만 일부가 틀리거나 과장됐다 | 예: 소위 통과를 "국회 통과"로 씀, 날짜·수치 일부 불일치 |
| `거짓` | 근거 자료와 핵심 내용이 반대다 | 예: 부결된 법안을 "통과"로 씀, 발의하지 않은 의원을 발의자로 씀 |
| `근거없음` | 판정 대상이지만 수집한 근거 자료에서 찾지 못했다 | 자료 범위 밖(지방의회, 소위원회 단계 등)이거나 아직 반영 전 |
| `판정대상아님` | 사실 주장이 아니거나 범위 밖이다 | 의견·전망·평가, 남의 말을 따옴표로 옮긴 것, 여론조사, 지방의회 |

헷갈리면 다음 순서로 고른다: 판정대상아님인가 → 근거를 찾았는가(없으면 근거없음) → 핵심이 맞는가(사실/일부사실) → 반대인가(거짓).

## 3. 라벨을 다는 방법

1. `09_데이터/processed/gold__candidates.csv`를 엑셀로 연다. 후보 문장과 근거 후보가 들어 있다.
2. 두 사람이 따로 `label_a`, `label_b`를 채운다. 서로 보지 않는다.
3. 근거를 찾았으면 `evidence_dataset`과 `evidence_id`(의안 BILL_ID, 법령일련번호, 결정례일련번호, 정책뉴스 NewsItemId)를 적는다. 근거 후보 칸에 없으면 직접 찾아 적는다.
4. 두 라벨이 다르면 토론해 `label_final`을 정하고, 이유를 `note`에 적는다.
5. 다 채운 행은 `gold__claims_evidence.csv`로 옮긴다(평가에 쓰는 최종 정답셋).

## 4. 거짓 사례 만들기

실제 기사에는 `거짓`이 드물어 그대로는 평가가 안 된다. `사실`로 확정된 주장을 바꿔 거짓 사례를 만든다. AI Hub 낚시성 데이터가 쓴 방식과 같다.

- 결과 뒤집기: 통과 → 부결, 위헌 → 합헌
- 수치 바꾸기: 찬성 178표 → 찬성 128표
- 대상 바꾸기: 발의 의원, 법안 이름, 조항 번호
- 단계 부풀리기: 소위 통과 → 본회의 통과 (`일부사실`용)

만든 행은 `made_by`를 `변형`으로 적어 원문 주장과 구분하고, 평가 때 원문·변형 결과를 따로 보고한다.

## 5. 목표 수량

- 원문 주장 100개 이상, 그중 판정 대상(사실·일부사실·거짓·근거없음) 60개 이상
- 변형 거짓 사례 40개 이상
- 주장 유형별로 최소 10개
