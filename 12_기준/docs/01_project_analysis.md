## 과제

- 이름: 인공지능 활용 온라인 정보 분석 및 검증 서비스 연구
- 내용: 생성형 AI로 뉴스·온라인 게시글의 신뢰성을 분석하고, 판단 근거와 출처를 함께 보여주는 서비스 설계
- 형태: 지엔소프트(주) 프로젝트형 일경험, 8주, 4인 팀

## 제안서 요구사항

- 세대·성별 갈등 표현 분석
- 개체명 인식(NER)
- 키워드·규칙 기반 방식의 한계 분석과 모듈별 후보 모델 비교
- 성능평가: Accuracy, Precision, Recall, F1과 오탐·미탐 분석
- 뉴스 URL 또는 텍스트를 넣는 웹 프로토타입
- 수집·파싱·전처리 파이프라인
- 코칭 3회: 2주차 NLP·NER, 4주차 파싱·플랫폼 설계, 7주차 성능평가
- 제안서 2쪽 '예상 결과물' 목록은 원본에서 중간에 끊겨 있다 (확인 필요)

## 회사 미팅에서 나온 것

- 포괄적 뉴스는 성능이 떨어진다. 어느 분야를 할지 좁혀라.
- 신뢰성 확보에는 기관 자료·API(국세청, 법제처 등)가 중요하다.
- 파이프라인: 데이터 수집(뉴스 크롤링) → 정제 → 파싱
- 이벤트가 생길 때마다 크롤링하는 구조
- 거짓 뉴스 판단 기준이 필요하다.
