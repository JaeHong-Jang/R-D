# 수집 준수 규칙

점검일: 2026-11-26 (robots.txt와 기사 하단 문구를 직접 확인)

## 지키는 것

- CR-01: 수집 전에 각 사이트 `robots.txt`를 읽고 금지된 주소는 받지 않는다. 읽지 못하면 받지 않는다(`news_press.py`가 자동으로 함).
- CR-02: 같은 사이트에는 1.5초 이상 간격을 둔다. 법제처 API는 1초 간격.
- CR-03: 브라우저인 척하는 User-Agent를 쓰지 않는다. 차단(403)되면 그 사이트는 뺀다.
- CR-04: 기사에 "AI 학습·활용 금지"가 적혀 있으면 robots.txt가 허용해도 뺀다.
- CR-05: 수집한 기사 본문은 내부 분석용으로만 쓰고 공개하지 않는다.

## 언론사 현황

| 언론사 | 상태 | 이유 |
|---|---|---|
| 뉴시스, 프레시안, 오마이뉴스, SBS, 동아일보 | 수집 | robots.txt 허용 |
| 한겨레, 중앙일보, 노컷뉴스 | 수집 (확인 필요) | 일반 크롤러는 허용, AI 봇(GPTBot 등)은 차단. 회사 확인 필요 (harness Q-003) |
| 정책브리핑 | 수집 (효과 낮음) | 허용되지만 본문이 첨부파일이라 대부분 실패 |
| 연합뉴스, YTN | 제외 | 기사마다 "AI 학습 및 활용 금지" 명시 |
| MBC | 제외 | robots.txt 전면 금지 |
| 경향신문 | 제외 | 크롤러 요청에 403 |
| 조선일보, KBS, JTBC | 제외 | 본문을 자바스크립트로 만들어 이 방식으로는 추출 불가 |
| 네이버 뉴스, 다음 뉴스 | 제외 | robots.txt 전면 금지. 네이버는 AI 학습·RAG 목적 수집을 명시적으로 금지 |
